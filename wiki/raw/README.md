# raw/ — sources (never edit after adding)

Drop source material here, then ask the agent to ingest it.

- `notes/`: quick notes, ideas, things you learned
- `meetings/`: meeting and call notes (template: `../templates/meeting-note.md`)
- `documents/`: PDFs, price lists, supplier documents, screenshots, exports

Name files `YYYY-MM-DD-short-description.ext`. No passwords, API keys or customer personal data.
